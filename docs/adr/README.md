# Архитектурные решения (ADR)

Записи фиксируют значимые решения MVP и их последствия. Формат: контекст, решение, последствия, рассмотренные альтернативы. Статус «Принято» означает, что решение действует; «Предварительно» — что оно зависит от ещё не согласованной спецификации.

| Номер | Решение | Статус |
|---|---|---|
| [0001](0001-dot-as-storage-format.md) | DOT как формат хранения семантической модели | Принято |
| [0002](0002-typed-domain-model.md) | Типизированная доменная модель в памяти | Принято |
| [0003](0003-llm-proposes-application-applies.md) | LLM предлагает изменения, приложение проверяет и применяет | Принято |
| [0004](0004-layered-ports-and-adapters.md) | Слоистая архитектура и порты-адаптеры | Принято |
| [0005](0005-stable-identifiers.md) | Стабильные идентификаторы, независимые от названий | Принято |
| [0006](0006-atomic-patches-and-revisions.md) | Атомарные патчи и ревизии графа | Принято |

Новые записи нумеруются последовательно и не переписывают предыдущие. Изменение действующего решения оформляется новым ADR со ссылкой на заменяемое.
